# Pro Mats — redesign concept

Статичний responsive-лендинг для Pro Mats, зібраний на основі контенту й реальних фото з чинного сайту та бренд-сигналів з Instagram `@pro_mats_ua`.

## Локальний запуск

```bash
cd pro-mats-redesign
python3 -m http.server 4173
```

Відкрити: `http://127.0.0.1:4173/`

## Структура

- `index.html` — семантична розмітка та контент;
- `css/styles.css` — дизайн-система, desktop/mobile layout, анімації;
- `js/main.js` — меню, reveal-анімації, вибір кольорів і демо-валідація форми;
- `assets/img` — локальні оптимізовані фото й логотип Pro Mats.

## Перед production-запуском

1. Підключити `#lead-form` до CRM або форми Weblium/іншого бекенду.
2. Уточнити актуальні ціни, строки виготовлення та умови передоплати.
3. Замінити `noindex` і `robots.txt`, коли сторінка буде готова до індексації.
4. Додати production-аналітику та юридичні сторінки.
